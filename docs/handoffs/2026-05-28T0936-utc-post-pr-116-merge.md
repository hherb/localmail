## Project context (1-minute version)

`localmail` mirrors IMAP accounts (Gmail OAuth, password) into Postgres.
**Strictly read-only with respect to IMAP**. Downstream consumers read
the DB + attachment tree directly or via the `localmail serve` HTTPS API.
The Tauri 2 + Svelte 5 desktop GUI lives at [gui/](gui/). The HTTPS
admin UI (Sub-plan 1) ships under [src/localmail/serve/admin/](src/localmail/serve/admin/)
and [src/localmail/api/admin/](src/localmail/api/admin/).
See [CLAUDE.md](CLAUDE.md), [README.md](README.md),
[docs/operations/upgrade-runbook.md](docs/operations/upgrade-runbook.md),
[docs/operations/admin-ui-smoke.md](docs/operations/admin-ui-smoke.md),
and
[docs/superpowers/specs/2026-05-17-localmail-gui-design.md](docs/superpowers/specs/2026-05-17-localmail-gui-design.md).

## What's next

### 1. **#113** admin UI: server-side session revocation *(immediate, recommended)*

Sub-plan 2 candidate. The cookie-based admin session has no
revocation hook — leaked or stolen tokens stay valid until the
JWT's `exp`. Resolution sketch from the issue body's option 1:

- Add migration `0022_api_users_sessions_invalidated_at.sql`
  introducing a `sessions_invalidated_at timestamptz` column
  (default NULL) on `api_users`.
- Extend the session token decoder
  (`localmail.api.admin.session_tokens.decode_session_token`)
  + `get_admin_user` dependency to reject tokens whose
  `issued_at < sessions_invalidated_at`.
- Add a `localmail revoke-admin-sessions USERNAME` CLI command
  that bumps the column to `now()`.
- Regression test: issue a token, bump
  `sessions_invalidated_at`, confirm the next
  `require_admin_session` request 401s.
- Acceptance: `uv run pytest -q tests/test_admin_*.py
  tests/test_serve_admin_*.py` green; mypy clean on touched
  files; one-line update to CLAUDE.md "Schema essentials" if
  the new column warrants it (it likely does — it's an
  operator-facing revocation knob).

## Open decisions & risks

1. **Deprecation alias removal timing.** The PEP 562 `__getattr__`
   now emits `DeprecationWarning` on every underscored-import
   site. After one release with the warning in place, a
   follow-up issue can drop the `_DEPRECATED_ALIASES` table and
   the `__getattr__` entirely. Not urgent — no current code
   imports the underscored names.

2. **CLAUDE.md not updated for PR #116.** Deliberate: the
   `__getattr__` mechanism is module-local. If a future PR
   touches the auth public surface again it might warrant a
   single-line CLAUDE.md note ("api/auth canonical public
   surface is `DUMMY_PASSWORD_HASH`, `check_login_rate_limits`,
   `record_login_attempt`; `__all__` is authoritative"), but
   landing that now would be premature.

3. **`.claude/settings.local.json` stays untracked.** Same as
   prior sessions — local-only file.
